Camxora 1.7.1
Matched background and thumbnail prompt library
November 18, 2026

What's new
----------
- The desktop image pipeline now uses the new matched background and thumbnail
  prompt library from the admin portal.
- Background generation uses all active background prompts instead of the old
  JBL portable-speaker collection filter.
- Admin-library thumbnails now run legacy thumbnail prompts as-is with the
  generated background as the reference image.
- Thumbnail text presets remain available for future lockup styles, but no
  longer block generation when the active thumbnail styles are legacy prompts.

Changed
-------
- This release is a forced update so every desktop client is on the current
  version.

Requirements
------------
- Installer: CamxoraSetup-1.7.1.exe
- Production API: https://api.camxora.com/api/v3

Still included
--------------
- Three image sources: Prompt only, Category, and Admin library.
- Background-referenced thumbnail generation.
- 20,000-character image prompt limit.
- Suno V6 model series plus V5.5 / V5 options.
- YouTube upload automation for connected channel profiles.
