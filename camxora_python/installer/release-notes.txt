Camxora 1.2.1 - Ship-safe preview (HDR bloom off)
Date: 2026-08-05

What's new
----------
- Preview HDR bloom is **off by default** again (same look as before 1.1.0
  CapCut bloom). Fixes missing particles, missing stage logo, spectrum white
  haze, and ugly lightning corona that appeared when bloom was default-on
- Keep the 1.2.0 windowed click / dropdown hit-test fix
- Optional: set CAMXORA_PREVIEW_HDR_BLOOM=1 to re-enable CapCut-style bloom
  (experimental until composite order is fixed)

Also included
-------------
- 1.2.0 windowed UI click hit-test fix (opaque shell, DWM/QSS rounding)
- Export WYSIWYG spectrum/logo/lightning parity (from 1.1.0)
- Preview Alpha_Lock / GL diagnostics / Raise Scroll import fix
- Per-device media folders, Spectrum Save / Row Width, NVENC→x264 fallback

Not included in this build
--------------------------
- DistroKid automation / WAV add-on (kept on a separate branch until ready)
- Playlist glass polish (kept out until ready)
- Full HDR bloom composite fix (particles/logo after resolve) — coming next

Notes
-----
- Production API only
- API: https://api.camxora.com/api/v1
- Installer file: CamxoraSetup-1.2.1.exe
- Older NVIDIA drivers (below 570): export uses x264; update the driver + restart
  Camxora to use NVENC again
