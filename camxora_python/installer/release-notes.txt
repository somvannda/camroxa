Camxora 1.4.4
Build info + export duration fixes
September 25, 2026

What's new
----------
- The app now reports its real version in diagnostics and logs. Previously it
  sent a placeholder, so support could not confirm which build a user was on.
- Video export duration fix (from 1.4.2): exported MP4s now match the MP3
  length. Some 48 kHz VBR MP3s were decoded short; the export now decodes them
  fully, and existing audio-analysis caches are cleared on upgrade.
- Downloaded MP3s now carry a correct duration header, so the MP3 and the
  exported video report the same length.
- Video/merge credit preflight (from 1.4.3): a music plan can no longer start
  and then stall at the export stage for lack of credits.

Still included from 1.4.1
-------------------------
- Suno V6 model series (V6, V6 Mini, V6 Wild) plus V5.5 / V5 options.
- V6 available on the CAMXORA music web Create page:
  https://music.camxora.com/create

Requirements
------------
- Installer: CamxoraSetup-1.4.4.exe
- Production API: https://api.camxora.com/api/v3

Not in this build
-----------------
- DistroKid / WAV add-on
