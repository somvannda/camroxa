Camxora 1.1.1 - Image Prompt only & Manual Generation queue rows
Date: 2026-08-05

What's new
----------
- Preferences: Background / Thumbnail source = Category | User reference |
  Prompt only (under AI Generated). Overlay UI hidden.
- Image page: source combos above previews, Manual Generation under each
  prompt, Retry vs Regenerate (force) menus, quieter background poll
- Deselect + Manual Generation creates a today-dated **Not available**
  Image queue row and generates via the normal billed image-job path
- Prompt only: generate BG/TH from your prompts with no Category sample
- Includes 1.1.0 ship-safe preview (HDR bloom off by default) and windowed
  click hit-test fix

Requires matching production API
--------------------------------
- Prompt-only image modes, force regenerate, POST /image-jobs/manual-generate
- Database migration 082 (song_count may be 0 for manual image rows)

Not included in this build

- DistroKid automation / WAV add-on (separate branch)
