Camxora 1.4.2
Video export duration fix + UI cleanups
September 23, 2026

What's new
----------
- Video export now matches the MP3 length. Some 48 kHz VBR MP3s were decoded
  short (libsndfile/minimp3), producing a shorter MP4 and the error "video
  export did not produce a usable output". The export now decodes them fully.
- Existing audio-analysis caches are invalidated on upgrade, so the decode fix
  takes effect without manually clearing the cache.
- Merge only proceeds when the exported MP4 actually matches the audio length.
- Studio is hidden from the desktop sidebar.
- No more ffmpeg console popups during export and merge.

Still included from 1.4.1
-------------------------
- Suno V6 model series (V6, V6 Mini, V6 Wild) plus V5.5 / V5 options.
- V6 available on the CAMXORA music web Create page:
  https://music.camxora.com/create

Requirements
------------
- Installer: CamxoraSetup-1.4.2.exe
- Production API: https://api.camxora.com/api/v3

Not in this build
-----------------
- DistroKid / WAV add-on
