Camxora 1.0.15 - Multi-machine paths, spectrum flush drag, startup retry (+ 1.0.14 merge)
Date: 2026-08-03

What's new
----------
- Same Camxora account on two PCs: ignore the other Windows user's
  C:\Users\... paths (no more PermissionError spam); use this PC's folders
- Spectrum / logo / lightning can drag flush to the top and bottom of preview
- Stronger startup retry when Windows Defender briefly blocks pydantic import
- Continue / Start Merging no longer requires export background PNG or catalog template
- Clearer export readiness errors when Start Export is blocked
- Honest API-recovery toasts (only "resuming" when a run actually starts)

Notes
-----
- Production API only
- API: https://api.camxora.com/api/v1
- Installer file: CamxoraSetup-1.0.15.exe
- Force auto-update publish of CamxoraSetup-*.exe needs the matching
  platform_api + admin portal hotfix (filename parse) deployed separately
