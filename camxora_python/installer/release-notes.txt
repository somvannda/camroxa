Camxora 1.2.0 - Windowed UI click fix
Date: 2026-08-04

What's new
----------
- Windowed mode: dropdowns, calendars, scrollbars, and buttons click where they
  look again (hit-testing no longer offset from painted controls)
- Keep the custom rounded header; rounding now uses Windows DWM + QSS on an
  opaque shell instead of a translucent window mask
- Maximized mode was already fine; windowed mode now matches that behavior

Also included (from 1.1.0)
--------------------------
- Real HDR bloom on by default for preview and export (set
  CAMXORA_PREVIEW_HDR_BLOOM=0 to force the legacy glow path)
- Export matches the live Video preview (spectrum instances, live draft
  style/position, lightning flash undersampling)
- Logo inspector: Reset Center restored
- Fixes black live preview after Alpha_Lock (ModernGL alpha clear wipe)
- Fixes GPU export crash on some drivers (GLSL smoke_hash_noise2)
- Failed-export refunds clamp reason to 500 chars; music preflight skips
  inverted From/To dates
- Includes 1.0.20 Raise Scroll import fix and the P0–P4.3 preview stack
- Per-device media folders, Spectrum Save / Row Width, NVENC→x264 fallback

Not included in this build
--------------------------
- DistroKid automation / WAV add-on (kept on a separate branch until ready)
- Playlist glass polish (kept out until ready)

Notes
-----
- Production API only
- API: https://api.camxora.com/api/v1
- Installer file: CamxoraSetup-1.2.0.exe
- Older NVIDIA drivers (below 570): export uses x264; update the driver + restart
  Camxora to use NVENC again
