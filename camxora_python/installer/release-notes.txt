Camxora 1.2.0
Progress paths, missing MP3s, export merge & Quality
August 6, 2026

What's new
----------
• Progress remaps run folders to this PC’s Suno root (no more foreign
  absolute paths breaking Open / downloads).
• Right-click Download missing MP3s (N) for the selected channel role —
  fills gaps from existing Suno/Backblaze URLs (no re-Suno).
• Music % / X/Y follow MP3s on disk; Done/Completed/YouTube menus drop
  Continue/Stop/export retries (keep Open / Change Run Folder / rebuild).
• Progress Active only + Stage filters apply before Limit.
• Export: Recommended bitrate, Quality / Best Quality tiers, safer
  workers; manual merge finds real outputs; merge is lossless stream-copy
  with a usable-MP4 gate.
• Cleaner ConnectError copy on release builds; Image source UI shows
  Category + Prompt only (User reference hidden until P2).

Also included from 1.1.1
------------------------
• Image Prompt only, Manual Generation “Not available” rows, force
  Regenerate.
• Ship-safe preview (HDR bloom off by default) and windowed click fix.

Requirements
------------
• Production API already deployed for album/run-dir lock, Alt CDN heal,
  relative run keys, null sample-path guard, and image prompt modes.
• Installer: CamxoraSetup-1.2.0.exe
• Publish this release in Admin → Software Updates with Force update
  (mandatory) enabled so older clients must install.
