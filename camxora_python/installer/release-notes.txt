Camxora 1.4.0
Suno V6 music models
September 23, 2026

What's new
----------
• Create now generates with Suno V6 — the current model series. Pick
  V6 (default), V6 Mini (faster), or V6 Wild (more experimental) from the
  model selector.
• V6 songs use the dedicated lyrics field, so the exact lyrics you write are
  sung, with richer vocals and more natural detail.
• Negative tags can be up to 1000 characters on V6.
• Settings → Default Suno version now offers v6, v6 mini, and v6 wild.
  Existing v5 / v5.5 selections keep working.

Requirements
------------
• Installer: CamxoraSetup-1.4.0.exe
• Production API: https://api.camxora.com/api/v3
• Publish with Force update so older clients upgrade on app open.

Not in this build
-----------------
• DistroKid / WAV add-on
