Camxora 1.3.0
Regenerate missing/broken MP4s + real Suno MP3 + export hang fix
August 15, 2026 (same 1.3.0 stamp)

What's new
----------
• Suno downloads: use the real {id}.mp3 from the CDN instead of {id}.m4a
  (Opus in MP4 saved with an .mp3 name). If MPEG is not ready, Camxora
  waits and retries instead of keeping a fake MP3.
• Export: an Opus-in-MP4 file named .mp3 no longer hangs the whole queue.
  ffmpeg decodes it; one bad track is retried then skipped so the album
  can continue. Manual Export uses the same decoder.
• Progress: Regenerate missing/broken MP4s re-exports only tracks whose
  file is missing, tiny, corrupt, or truncated. Regenerating one track
  rebuilds a specific song from its MP3. You do not restart music or
  images. Start Merging and Continue Progress repair those files first,
  then write MERGED_*.mp4. Credits are charged only for tracks that
  actually re-export.
• Progress Merge: Start Merging either writes MERGED_*.mp4 in the run
  folder or shows an error. It no longer finishes “successfully” with no
  file. Older exported albums can merge if the tracks match each other
  (not only today’s FPS / 48 kHz). Nested run folders are found; a stale
  MERGED file is rebuilt if tracks were re-exported.
• Preferences Suno output dir: a saved folder (for example D:\Suno
  Generated) is kept across installer upgrades. The app no longer resets
  it to AppData Media\Suno if the drive is offline or a leftover path
  file was left at the Camxora root.
