Camxora 1.2.0 - Windowed UI click fix
Date: 2026-08-04

What's new
----------
- Windowed mode: dropdowns, calendars, scrollbars, and buttons click where they
  look again (hit-testing no longer offset from painted controls)
- Keep the custom rounded header; rounding now uses Windows DWM + QSS on an
  opaque shell instead of a translucent window mask
- Maximized mode was already fine; windowed mode now matches that behavior

Also included (from 1.0.19 line)
--------------------------------
- Per-device media folders for the same Camxora account on multiple PCs
- Progress / Auto-Video see remapped local folders without restart
- Spectrum Save / Row Width / Raise Scroll fixes
- Video export: older NVIDIA drivers fall back to software encode (x264)
  instead of failing when NVENC is too old

Not included in this build
--------------------------
- DistroKid automation / WAV add-on (kept on a separate branch until ready)
- Playlist glass polish (kept out until ready)

Notes
-----
- Production API only
- API: https://api.camxora.com/api/v1
- Installer file: CamxoraSetup-1.2.0.exe
- Older NVIDIA drivers (below 570): export uses x264; update the driver + restart
  Camxora to use NVENC again
