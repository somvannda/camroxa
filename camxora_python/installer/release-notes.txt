Camxora 1.1.0 - Ship-safe preview (HDR bloom off)
Date: 2026-08-05

What's new
----------
- Preview HDR bloom is **off by default** (legacy glow path). Particles, stage
  logo, spectrum, and lightning behave correctly out of the box
- Optional: set CAMXORA_PREVIEW_HDR_BLOOM=1 to try CapCut-style bloom
  (experimental until composite order is fixed)
- Windowed UI click hit-test fix: dropdowns, calendars, scrollbars click where
  they look (opaque shell + DWM/QSS rounding)
- Export matches live Video preview (spectrum instances, live draft
  style/position, lightning flash undersampling)
- Logo inspector: Reset Center restored
- Fixes black live preview after Alpha_Lock; GLSL smoke_hash_noise2 export crash
- Failed-export refunds clamp reason to 500 chars; music preflight skips
  inverted From/To dates
- Includes 1.0.20 Raise Scroll import fix and the P0–P4 preview stack
- Per-device media folders, Spectrum Save / Row Width, NVENC→x264 fallback

Not included in this build
--------------------------
- DistroKid automation / WAV add-on (kept on a separate branch until ready)
- Playlist glass polish (kept out until ready)

Notes
-----
- Production API only
- API: https://api.camxora.com/api/v1
- Installer file: CamxoraSetup-1.1.0.exe
- Older NVIDIA drivers (below 570): export uses x264; update the driver + restart
  Camxora to use NVENC again
