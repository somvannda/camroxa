Camxora 1.4.0
Suno V6 music models
September 23, 2026

What's new
----------
• Suno V6 model series support: V6 (default), V6 Mini (faster), and
  V6 Wild (more experimental).
• V6 is available on the CAMXORA music web Create page:
  https://music.camxora.com/create
• Settings → Default Suno version now offers v6, v6 mini, and v6 wild.
  Existing v5 / v5.5 selections keep working.
• V6 songs use the dedicated lyrics field for richer vocals and more
  natural detail. Negative tags can be up to 1000 characters.

Requirements
------------
• Installer: CamxoraSetup-1.4.0.exe
• Production API: https://api.camxora.com/api/v3
• Force update: older clients upgrade on app open.

Not in this build
-----------------
• DistroKid / WAV add-on
