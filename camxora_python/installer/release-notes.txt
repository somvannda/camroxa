Camxora 1.1.1
Image Prompt only & Manual Generation
August 5, 2026

What's new
----------
• Choose how Background and Thumbnail images are made: Category,
  User reference, or Prompt only (Preferences → AI Generated).
• Prompt only uses your text prompts — no Category sample image.
• On the Image page, pick the source above each preview and run
  Manual Generation under the prompt.
• With nothing selected, Manual Generation adds a today-dated
  “Not available” row to your Image queue and generates there
  (same billing as normal image jobs).
• Retry failed jobs, or Regenerate successful ones (force new run).
• Image page refreshes quietly in the background without resetting
  your prompts or flashing the UI.

Also included from 1.1.0
------------------------
• Ship-safe video preview (HDR bloom off by default).
• Windowed-mode click targeting fix.

Requirements
------------
• Production API with prompt-only image modes and Manual Generation
  support (already deployed for this release).
• Installer: CamxoraSetup-1.1.1.exe

Coming later
------------
• Theme categories, personal reference library, and Progress
  Replace/Export are not in this build.
