# Authentication

All requests require a Bearer token in the Authorization header:

Authorization: Bearer YOUR_API_KEY

Base URL: https://musicapi.camxora.com (use http://localhost:3000 for local dev).

# Endpoints

POST/v1/music

Generate music from a description or your own lyrics.

curl -X POST https://musicapi.camxora.com/v1/music \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"gpt_description_prompt":"an upbeat pop song about summer"}'
POST/v1/lyrics

Generate lyrics from a prompt.

curl -X POST https://musicapi.camxora.com/v1/lyrics \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"a hopeful song about new beginnings"}'
POST/v1/music/extend

Extend an existing clip from a given timestamp (seconds).

curl -X POST https://musicapi.camxora.com/v1/music/extend \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"clip_id":"","continue_at":170}'
POST/v1/music/cover

Reinterpret an existing clip.

curl -X POST https://musicapi.camxora.com/v1/music/cover \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"clip_id":""}'
GET/v1/task/:id

Poll a job's status and result. Returns status (pending / running / complete / error) plus result when done.

curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://musicapi.camxora.com/v1/task/<job_id>
GET/v1/credits

Check remaining credits for your API key.

curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://musicapi.camxora.com/v1/credits

# Callbacks

Pass callback_url in any request body to receive a webhook when the job completes. The callback POSTs:

{
  "job_id": "...",
  "type": "music",
  "status": "complete",
  "account_id": "acct-1",
  "result": { "clips": [ { "media_urls": [ { "url": "https://..." } ] } ] },
  "error": null
}
