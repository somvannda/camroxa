free Account created

▼
monthly 50 free credits / 30 days

Reset, not stacked — the balance never exceeds 50. Granted on email confirmation or Google sign-in.

▼

2 · Buy a pack

Choose a pack

/api/v3/topups/packs/public → Small / Medium / Pro / Large.

▼
Checkout

POST /api/v3/topups/purchase → CutLuy / Chmaba hosted page.

▼
Webhook paid

handle_topup_webhook verifies signature, then calls sync_topup_pack.

▼
pack Mint pack lot

Wallet +credits, one pack lot, expiry = now + 30 days. Live lots are re-stamped to the same date.

▼
Tier = Pro

is_pro = exists a live pack lot. Desktop + web unlocked.

3 · Generate

Request

Song / image / draft / export. Price comes only from the pricing table.

▼
Quote

quote(op) → credits. No plan lookup.

▼
Balance gate

Requires wallet ≥ cost. Free with trial credits passes.

▼
free Preview cap

V6-Pro and V6-Wild: 1 each per month, 60 seconds. V6-Mini is always full-length.

▼
ledger Atomic debit

One transaction: wallet −cost, lots decremented FIFO by expiry, credit_transactions row.

▼
refund Provider fails

refund_once → wallet +cost and the credits return to a live lot. Never double-refund.

4 · Expiry

Daily sweep

grant_maintenance → expire_lapsed_lots.

▼
pack 30 days pass

Pack credits lapse. Wallet is clawed back, lot zeroed.

▼
Tier = Free

No live pack lot. Library and re-download still work; generation needs a top-up.

▼
legacy Converted plan credits

Lots marked legacy_conversion_2026_10_30 move their remainder to a non-expiring grant lot — credits kept, tier drops to Free.

▼
Buy again

New pack lot → Pro again. Expiry is re-stamped on every purchase.

Free 0 or 50

No live pack. 50 trial credits on signup. Can generate while credits last; no desktop after trial.

Pro live pack

At least one unexpired pack lot with credits. Full product. 30-day expiry.

Exhausted 0 credits

Was Pro, spent everything. Library + re-download only. Top up to generate again.
