# Studio Spectrum — tip taper, glow 0, clearer palettes

## Changes
- **Tip taper** Shape slider (0 = equal width top-to-bottom, 1 = pointed tips). Default 0.
- **Glow 0 works** — fixed `0.0 or 0.45` bind/compile bugs; expert Glow 0 fully disables bloom.
- **Clearer palettes** — more neon catalog stops, new **Rainbow** palette, spectrum path clarifies + slight sat boost for cleaner “true color” bars.

## Tip
- For the classic EQ look: Tip taper 0, Glow 0, Palette **Rainbow**, Material matte/wireframe as needed.
