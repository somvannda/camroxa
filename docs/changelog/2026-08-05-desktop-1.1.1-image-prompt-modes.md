## User-facing summary

Camxora **1.1.1** lets you control how Background and Thumbnail images are generated, generate from prompts alone, and create Image queue rows without a song selected.

### Preferences

- Under **AI Generated**, **Background source** and **Thumbnail source** are each:
  - **Category** — use a Category sample (previous default behavior)
  - **User reference** — reserved; shows not-ready until personal refs ship (P2)
  - **Prompt only** — generate from your prompt text with no sample image
- Overlay UI is hidden for this ship.
- **User Provided** media hides the AI source controls (as before).

### Image page

- Source-mode combos above Background / Thumbnail previews (synced with Preferences).
- **Manual Generation** under each prompt.
- With a song/queue row selected: generates for that row.
- With nothing selected: creates a today-dated **Not available** queue row, selects it, and generates via the normal billed image-job path.
- **Retry** (failed) vs **Regenerate** (force reset of successful jobs).
- Quieter ~12s poll: does not reset controls or flash chrome; reloads previews only when output changes.

### Image queue

- **Regenerate Background + Thumbnail** (force).

## Platform API (required with this installer)

| Piece | Purpose |
|-------|---------|
| Prompt-only source modes | Skip sample refs for `prompt_only` BG/TH |
| `POST /image-jobs/retry` `force=true` | Regenerate successful jobs |
| `POST /image-jobs/manual-generate` | Not available batch + BG/TH jobs |
| Migration `082` | `batches.song_count` may be `0` |
| Image worker restart | Must run new code after API deploy |

Production: API + migration `082` + worker restart applied for this ship.
