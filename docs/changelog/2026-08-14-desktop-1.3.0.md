# Desktop 1.3.0 — Regenerate missing/broken MP4s

**Date:** 2026-08-14  
**Surfaces:** `camxora_python` (`CamxoraSetup-1.3.0.exe`)  
**Branch:** `release/desktop-1.2.6` (version stamp **1.3.0**)

## Summary

Feature cut over **1.2.6** (1.2.7 was stamped locally but never published). Users can
regenerate a missing, tiny, corrupt, or truncated MP4 from its MP3 without restarting
music/images, and Start Merging / Continue Progress repair those tracks before concat.

Also includes the unpublished 1.2.7 fixes:

1. Progress Merge showed “Merging…” but wrote no `MERGED_*.mp4`
2. Preferences Suno output dir reset to AppData `Media\Suno` after a new installer

## Verify

1. Install 1.3.0 — footer shows **1.3.0**.
2. On a 10-track run with one missing MP4: Progress → **Regenerate missing/broken MP4s**
   re-exports only that track, then merge can continue.
3. **Regenerate one track** on a healthy MP4 deletes and re-exports that file only.
4. **Start Merging** with one corrupt MP4 regenerates it, then writes `MERGED_*.mp4`.
5. Set Suno output dir to a custom folder, restart / reinstall 1.3.0 over 1.2.6 —
   Preferences still shows that folder.

## Force update (production)

Publish **1.3.0** with Force update so **1.2.6** clients upgrade on app open.
Same-version `1.2.6` cannot replace the already-shipped 1.2.6 installer.
1.2.7 was not published — do not ship a 1.2.7 installer.
