# Desktop 1.4.4 — build info + export duration fixes

**Date:** 2026-09-25
**Branch:** `release/desktop-1.4.4`
**Surfaces:** camxora_python (desktop)
**Status:** built and published (production, mandatory)

## Summary

Desktop **1.4.4** ships the telemetry version fix (PR #162) and rolls up the
1.4.2 export-duration fix and 1.4.3 video/merge preflight credits. It exists so
ops can finally verify which desktop build a user runs — while confirming the
MP3-duration fix rollout, production `video_export_telemetry` rows all reported
the placeholder `app_version = "camxora_python"`.

## Changes

- Telemetry (`pipeline_automation_service`), client logs (`log_sync`), and manual
  export telemetry (`video_view`) now use `get_app_version()`.
- Version bumped to **1.4.4** (`pyproject.toml`, `resources/app-version.txt`).
- `installer/release-notes.txt` refreshed for 1.4.4.

## Build / publish

- Built: `cd camxora_python; .\scripts\build-desktop.ps1 -Environment production -BuildInno`
  → `CamxoraSetup-1.4.4.exe` (416 MB; production API baked in; dist verification passed).
- Published to production as a **mandatory** (force-update) release. Installer stored
  as `Camxora-1.4.4.exe` in `/opt/camxora/repo/desktop_release_storage/`; 138 users
  notified. Public release: `https://api.camxora.com/api/v3/public/desktop-release`
  (initially published optional, then flipped to mandatory so users on ≤1.4.2 are
  still forced to the duration fix).

## Follow-ups

- `video_export_telemetry.app_version` and `client_log_batches.app_version` become
  usable for rollout verification once users upgrade to 1.4.4.
