# Studio — player repeat, solid graph, raise, layer audio, logo inside

## Player
- **Repeat** toggle on the playback bar.
- When a track ends (and Repeat is off), Pause flips back to **Play**.

## Spectrum
- **Solid graph** — filled base→tip graph instead of discrete bars.
- **Raise** — Top / Bottom / Left / Right / Outside shape / Inside shape.
- **Layer audio bus** — frequency-weighted mapping so Bass vs Treble actually look different.

## Logo
- **Logo inside shape** (was “Attach spectrum to logo”) — places logo in the hollow center; enabling it defaults Raise to Outside shape.
