# Desktop v1.0.1 production — frozen export Loading-audio / spectrum hotfix

**Date:** 2026-07-28  
**Status:** implemented — frozen smoke PASS (2× short parallel + 2× full-length parallel encodes)

## Summary

**CamxoraSetup-1.0.1.exe** — frozen installs hung on export. First packaging missed `soundfile`/`audioread`; then Unicode progress crashed into librosa fallback; then `librosa.resample` hung without soxr. After those fixes, logs showed decode+soxr OK but freeze on **Computing spectrum** (`librosa.stft`) because analysis ran **after** OpenGL init at **fps=60**, and dual workers oversubscribed OpenBLAS.

This rebuild: analyze before OpenGL, analysis fps=30, frozen BLAS=1 thread, defer pygame on GPU path, frozen-safe onset peak beats (avoid `beat_track` AV), and allow Preferences multi-worker again (low-VRAM still forced to 1).

Agents can verify without installing via `python camxora_python/scripts/smoke_frozen_export.py --parallel 2` against `dist/Camxora`.

## Product impact

- **Before:** Export stuck on Loading audio / Computing spectrum (especially with 2 workers).
- **After:** Spectrum/onset/beats complete; encoder starts; multi-worker allowed on mid/high GPUs.
