# Desktop v1.0.1 production — frozen export serial hotfix

**Date:** 2026-07-28  
**Status:** building for production distribution

## Summary

**CamxoraSetup-1.0.1.exe** — packaged (frozen) builds force **one** video-export worker so auto-video cannot spawn multiple `Camxora.exe --visualizer` processes that hang on `Loading audio…`.

## Product impact

- **Before (1.0.0 installer):** Preferences could run 2–4 parallel long exports; each cold-starts a full frozen exe + librosa and often freezes on Loading audio.  
- **After (1.0.1):** Installer always serializes exports (warm daemon allowed). Local `python main.py` still honors Preferences worker count (except low-VRAM tier).

## Technical impact

- `resolve_pipeline_export_workers()` returns `1` when `is_frozen_runtime()`
- Version bump `1.0.0` → `1.0.1`
- No DistroKid or unrelated surfaces in this build branch
