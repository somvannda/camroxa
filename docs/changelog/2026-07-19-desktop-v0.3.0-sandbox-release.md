# Desktop v0.3.0 sandbox release

**Date:** 2026-07-19  
**Status:** built for sandbox distribution

## Summary

Sandbox desktop installer **CamxoraSetup-0.3.0.exe** — Phase 1 GPU export performance: cached audio analysis, warm daemon, quality tiers, NV12 pipe, async readback, and export UX improvements.

## Product impact

- Pipeline exports default to **Draft** (720p, very fast) for much faster batch video generation.
- Second export of the same track skips minutes of audio analysis when cache is hit.
- Export status shows **NVENC** vs **CPU x264** and monotonic progress through initialization.
- Video tab **Tier** dropdown: Draft / Standard / Master.

## Technical impact (Phase 1)

| Area | Change |
|------|--------|
| REQ-1.1 | `shared/services/audio_analysis_cache.py` — disk STFT cache |
| REQ-1.2 | `features/video/services/visualizer_daemon.py` — warm export worker |
| REQ-1.3–1.4 | No FFmpeg vflip; export MSAA off |
| REQ-1.5–1.6 | `visualizer/readback.py` — NV12 pipe + async PBO readback |
| REQ-1.7 | Codec badge, fast defaults, monotonic progress |
