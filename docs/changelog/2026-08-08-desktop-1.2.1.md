# Desktop 1.2.1 — Image regenerate, Suno paths, prompt cap & startup

**Date:** 2026-08-08  
**Surfaces:** `camxora_python` (`CamxoraSetup-1.2.1.exe`)  
**Branch:** `release/desktop-1.2.1`  
**Requires:** production `platform_api` already on `main` (same as 1.2.0; image prompt 5000-char gate recommended)

## User-facing summary

Camxora **1.2.1** ships post-1.2.0 desktop fixes: stale local PNGs after
image regenerate, Preferences Suno root persistence, image prompt character
cap UI, startup OpenGL splash flash, and **on-open-only force update** (no
mid-session interrupt).

### Image

- **Regenerate Background / Thumbnail** overwrites the previous local PNG
  when production reuses the same output path.
- Prompt editors show live `current / 5000` and hard-cap at 5000 characters.

### Preferences / paths

- **Local Paths** keeps FFmpeg + **Suno output dir** only (this PC).
- Saving Preferences no longer rewrites the device Suno root from cloud
  account settings / AppData leftovers.

### Startup / force update

- Splash no longer flashes closed/reopened when Video GPU preview prewarms
  (`QOpenGLWidget` HWND); OpenGL primed before first `show()`.
- Mandatory updates gate **only when opening the app** (before login /
  relogin / studio), via public desktop-release — not mid-session push.

## Force update (production)

After building and uploading the installer:

1. Admin → **Software Updates** (or Desktop notifications software-update section).
2. Set version `1.2.1`, paste download URL / upload package.
3. Enable **Force update** / **mandatory**.
4. **Publish** so clients on **1.2.0** (and older) receive `software_update.available` and cannot dismiss.

See `docs/DESKTOP_DISTRIBUTION.md` → In-app force update.
