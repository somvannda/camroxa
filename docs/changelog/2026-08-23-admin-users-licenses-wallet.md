# 2026-08-23 — Admin users / licenses use the unified catalog

Sandbox only.

`/users` drops the Music/Studio Tag column. Plan is license first, else active CutLuy web plan, else Free. Credits is the shared wallet number (no daily used/limit).

`/licenses` lists desktop `licenses` and CutLuy `web_subscriptions` together, with a Source column. Assign/revoke/add-ons stay desktop-only.

User-spent plan filter includes web subscribers. Usage copy states leftover/pack belong on the ledger; Finance grant issued stays period/daily only.
