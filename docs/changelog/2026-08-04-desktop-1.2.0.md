# Desktop 1.2.0 — windowed UI click hit-test fix

**Date:** 2026-08-04  
**Surfaces:** `camxora_python` installer  
**Branch:** `bugfix/window-chrome-click-hit-test` → `main`  
**Installer:** `CamxoraSetup-1.2.0.exe`

## Summary

Ships the windowed-mode click fix (dropdowns / calendars / scrollbars / buttons
no longer require offset clicks) as **1.2.0**, on top of the 1.0.19 ship-safe
desktop line.

## Changes in this release

- Opaque frameless shell: no `WA_TranslucentBackground` + `setMask()` on the
  main window (that combo broke hit-testing under some Windows DPI setups).
- Rounding kept via Windows 11 DWM corner preference + QSS `border-radius` on
  `#window_surface`.
- Version stamp **1.2.0**; release notes updated.

## Still included from 1.0.19

- Per-device media roots + no-restart download/Progress remap
- Spectrum Save / Row Width / Raise Scroll
- Force-update Setup progress (1.0.15–1.0.16 line)
- NVENC driver fallback to libx264

## Not included

- DistroKid / WAV automation
- Playlist glass polish
