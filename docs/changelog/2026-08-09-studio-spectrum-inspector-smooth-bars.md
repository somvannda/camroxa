# Studio Spectrum — inspector clip fix + smoother bars

## Changes
- Inspector axis panels scroll again so Spectrum controls keep natural height (combos/buttons no longer crush/clip).
- Spectrum dropdowns use label-above layout; layer actions are a 2-row grid; right rail widened to 360.
- Classic spectrum bars use a mild tip taper (less “square stamp” when raising).
- Preview requests 4× MSAA; glow bloom is quieter when Blur is 0 so bars stay crisp.

## Tip
- Very high Bar width / Thickness (e.g. 3.0) still looks chunky — try ~1.0–1.5 width for a cleaner ring.
