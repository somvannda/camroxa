# Desktop 1.0.1 consolidated release (carry-forward version)

**Date:** 2026-07-29  
**Status:** implemented (installer built; not auto-published)  
**Branch:** `release/desktop-1.0.1`  
**Installer:** `CamxoraSetup-1.0.1.exe`

## Summary

Public desktop version stays **1.0.1**. Iterative git tags briefly used 1.0.2 / 1.0.3 while fixing Progress, Album 2 display guards, Completed freeze, and export-without-thumbnail. Those changes are folded into one installer stamped **1.0.1** so we do not jump users to 1.0.4. Carry this `1.0.1` stamp forward until the next intentional public bump.

## Product impact

**Before (early 1.0.1-only):** export packaging / Loading-audio fixes only.  
**After (consolidated 1.0.1):** same version number, plus Progress filters, Completed freeze, faster video start (background-only), and desktop Album 2 display guards. Secondary album uniqueness remains primarily on the live API.
