# Desktop v0.4.1 sandbox release

**Date:** 2026-07-25  
**Status:** built for sandbox distribution

## Summary

Sandbox desktop installer **CamxoraSetup-0.4.1.exe** — force-update install/restart reliability plus purple update-dialog progress bar polish on top of **0.4.0**.

## Product impact

- After **Update now**, the gate shows download then install status, Camxora exits, silent Setup finishes, and the app relaunches.
- Update progress bar uses brand purple gradient with a transparent track.

## Technical impact

- Orphan PowerShell helper (not kill-on-job-close); durable Setup under `%LOCALAPPDATA%\Camxora\updates\`.
- Version **0.4.1** stamped in pyproject / installer / footer.

## Files touched

- Update flow: `subprocess_utils.py`, `software_update_installer.py`, `software_update_worker.py`, `software_update_service.py`, `software_update_gate.py`, theme `deep_blue.py`
- Version/changelog: `pyproject.toml`, `app-version.txt`, `Camxora.iss`, `release-notes.txt`, `app_version.py`, `test_app_version.py`, `CHANGELOG.md`
- Docs: `docs/changelog/2026-07-25-force-update-install-restart.md`, `docs/changelog/2026-07-25-software-update-progress-purple.md`, this file

## Migration / deploy

1. Build: `cd camxora_python; .\scripts\build-desktop.ps1 -Environment sandbox -BuildInno`
2. Ship `dist/installer/CamxoraSetup-0.4.1.exe` via Admin → Software Updates (or direct install for testers still on 0.3.0/0.4.0).
3. Tag: `v0.4.1`.
