# Desktop 1.4.3 — video/merge preflight credits

**Date:** 2026-09-24
**Branch:** `release/desktop-1.4.3`
**Surfaces:** camxora_python (desktop), platform_api
**Status:** implemented; desktop built; publish (mandatory)

## Summary

Desktop **1.4.3** ships the video/merge credit preflight changes: a music plan can
no longer start unless draft + Suno + images **and** local video export + merge
(including today's account-wide daily caps) are covered. The Automation card shows
`N export · M merge` and real credits instead of `Later`, and the Create page's
Auto Video/Merge is now gated and billed instead of running free.

Server side (`platform_api`, already deployed to sandbox + production via PR #153):
`preflight_music_plan` and `preflight_batch_cost` price `local/video` +
`local/video_merge`, enforce daily caps, and extend `subscription_covers_batch`
with the video/merge monthly meters. `/credits/operation-costs` returns
`video` + `video_merge` unit prices.

## Desktop changes

- `shared/lib/music_costs.py` — video/merge terms in the plan estimate and total.
- Music view + Automation card — show `N export · M merge` and the credits.
- `features/create` — upfront gate (quota first, then wallet) before the first
  song; charges `consume_video_operation` per Version folder / merge, refunds on
  failure.
- Version bumped to **1.4.3** (`pyproject.toml`, `resources/app-version.txt`).

## Build / publish

- `CamxoraSetup-1.4.3.exe` built (production env, Create page included).
- Uploaded and published as a **mandatory** (force-update) release via the admin
  software-update API; public release:
  `https://api.camxora.com/api/v3/public/desktop-release`.
