# Desktop 1.2.2 — Suno Structure, video WYSIWYG, lightning cap

**Date:** 2026-08-11  
**Surfaces:** `camxora_python` (`CamxoraSetup-1.2.2.exe`)  
**Branch:** `release/desktop-1.2.2`  
**Requires:** matching `platform_api` with Suno Structure (`structure_mode=suno`; no migration)

## User-facing summary

Camxora **1.2.2** ships post-1.2.1 desktop work already on `main`: Suno Structure
in Music Automation, preview/export spectrum + lightning WYSIWYG, lightning max
10 layers, export-settings save hardening, and sandbox dual-instance lock.

### Music

- Structure dropdown adds **Suno Structure** (native free section layout).
- Structure Shuffle stays off for AI Structure and Suno Structure.

### Video

- Manual Export hard-gates on preview vs export renderer JSON mismatch.
- Spectrum glow / Raise Scroll / Row Width and lightning sampling match preview.
- Lightning stack capped at **10** bolts (Add/Dup locked at cap).
- Rapid Resolution / FPS / Speed / Workers edits no longer crash
  `PatchSettingsWorker` (coalesced + local prefs mirror).

### Sandbox tooling

- Sandbox builds use a separate single-instance lock so they can run beside
  production. Production lock name is unchanged.

## Force update (production)

After building and uploading the installer:

1. Admin → **Software Updates**.
2. Set version `1.2.2`, paste download URL / upload package.
3. Enable **Force update** / **mandatory**.
4. **Publish** so clients on **1.2.1** (and older) receive the gate on app open.
