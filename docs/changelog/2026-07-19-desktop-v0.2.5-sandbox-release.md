# Desktop v0.2.5 sandbox release

**Date:** 2026-07-19  
**Status:** built for sandbox distribution

## Summary

Sandbox desktop installer **CamxoraSetup-0.2.5.exe** with GPU video export progress fixes so the Progress workspace reflects real initialization and encoding state instead of appearing frozen at 0%.

## Product impact

- During GPU export, users see step-by-step status (OpenGL setup, assets, audio analysis, encoder preparation) instead of a static ""Initializing GPU renderer..."" label.
- Status text continues to update even when the numeric progress bar is still at 0%.
- Multi-track exports show a blended overall progress percentage across tracks.

## Technical impact

- `camxora_python/visualizer/gpu_render.py` — init status messages during GPU renderer startup.
- `camxora_python/features/video/services/export_job.py` — progress throttling no longer drops message-only updates at 0%.
- `camxora_python/features/video/workers/pipeline_export_worker.py` — per-track GPU progress folded into overall `progressPercent`.
