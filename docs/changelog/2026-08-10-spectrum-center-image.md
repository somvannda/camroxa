# Spectrum-owned center image (Vizzy-style)

## Summary
Studio no longer lists Logo as a scene-tree node. Spectrum owns the center image (file, circle mask, size, opacity, reactivity). Selecting an image auto-enables attach-to-shape; clearing removes it. GPU still uses `assets.logo` + `spectrumAttachToLogo`.

## Surfaces
- Desktop Studio scene tree + Spectrum inspector
- Preview drag when Spectrum is selected and a center image is attached
