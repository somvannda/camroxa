# Studio Spectrum — Soft EQ, thinner bars, motion speed, per-layer audio

## Changes
- **Bar width** slider goes down to **0.08** (thinner preview bars).
- New shape **Soft EQ** — thin equal-width bars with rounded caps (reference look).
- **Motion speed** on Spectrum → Animation (restores controllable pulse/breathe/rotate rate).
- Each spectrum **layer** can pick its own **audio bus** + **Layer audio** gain.

## Tip
- Soft EQ look: Shape Soft EQ · Bar width ~0.15–0.4 · Tip taper 0 · Glow 0 · Palette Neon Pink / Rainbow.
