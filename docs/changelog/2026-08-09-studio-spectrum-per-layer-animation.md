# Studio Spectrum — per-layer controls + animation dials

## Layers
- Each layer owns bar height/width/thickness/count, tip taper, mirror, raise, solid graph, peak caps, glow, blur, opacity, audio bus.
- Rename layers via the Name field.
- Add / Dup / Del / Up / Down are icon buttons on one row.

## Animation
- Beyond Motion speed: Scale amount, Opacity pulse, Rotate amount, Audio drive, Kick impact, Smoothing.
