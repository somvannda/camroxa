# Desktop v0.4.0 sandbox release

**Date:** 2026-07-25  
**Status:** built for sandbox distribution

## Summary

Sandbox desktop installer **CamxoraSetup-0.4.0.exe** — Music Moods, History rewrite/recovery tooling, Progress export/merge control, and export cancel/throughput fixes since **0.3.0**.

## Product impact

**Before (0.3.0)**
- Phase 1 export performance (cache, warm daemon, Draft tier).
- Limited History recovery and Progress cancel UX.

**After (0.4.0)**
- Moods on batch create + History/Settings.
- History rewrite album/title/lyrics, status multi-select, delete failed batch, Recover failed + background pipeline helper.
- Progress Cancel / Stop Exporting / Continue Progress / reliable Start Merging.
- Safer quit during auto-video; calendar/date-filter and plan-estimate fixes.

## Technical impact

- Desktop: `camxora_python` version **0.4.0** (`pyproject.toml`, installer notes, footer stamp).
- Depends on sandbox **platform_api** moods + related migrations (`069`–`071`) and rewrite/delete endpoints already in this branch.
