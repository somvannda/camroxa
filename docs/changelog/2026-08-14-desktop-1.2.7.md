# Desktop 1.2.7 — Progress Merge + Suno folder persistence

**Date:** 2026-08-14  
**Surfaces:** `camxora_python` (`CamxoraSetup-1.2.7.exe`)  
**Branch:** `release/desktop-1.2.6` (version stamp **1.2.7**)

## Summary

Patch cut over **1.2.6** for two production bugs:

1. Progress Merge showed “Merging…” but wrote no `MERGED_*.mp4`
2. Preferences Suno output dir reset to AppData `Media\Suno` after a new installer

Plus hardening: nested run folders, stale MERGED rebuild, device-path backup,
last-user persist so the custom Suno folder is not written to the AppData root.

## Verify

1. Install 1.2.7 — footer shows **1.2.7**.
2. On a 10-track exported run, Start Merging writes `MERGED_*.mp4` (or a real error).
3. Set Suno output dir to a custom folder, restart / reinstall 1.2.7 over 1.2.6 — Preferences still shows that folder.

## Force update (production)

Publish **1.2.7** with Force update so **1.2.6** clients upgrade on app open.
Same-version `1.2.6` cannot replace the already-shipped 1.2.6 installer.
