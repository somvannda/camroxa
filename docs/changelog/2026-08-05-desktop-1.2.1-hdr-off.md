# Desktop 1.2.1 — HDR bloom default off (ship-safe)

**Date:** 2026-08-05  
**Surfaces:** `camxora_python` installer  
**Branch:** `release/desktop-1.2.1-hdr-off` → `main`  
**Installer:** `CamxoraSetup-1.2.1.exe`

## Why

1.2.0 included 1.1.0’s CapCut-style HDR bloom **on by default**. That stacked
with Bass Drive soft-glow and wiped particles / stage logo draws, and made
spectrum haze + lightning corona look wrong.

Users confirmed `CAMXORA_PREVIEW_HDR_BLOOM=0` restores correct preview. This
release bakes that default into the app (unset env → bloom off).

## Version note

- **1.0.20** → **1.1.0** (HDR bloom + export WYSIWYG) already landed on `main`
- **1.2.0** = windowed click hit-test fix on top of 1.1.0 (correct next minor)
- **1.2.1** = ship-safe cut: keep 1.2.0 click fix, turn HDR bloom default **off**

Do not re-stamp as 1.1.0 — that version already shipped with bloom on.

## Change

- `preview_hdr_bloom_enabled()` defaults to **false** when env is unset
- Opt-in: `CAMXORA_PREVIEW_HDR_BLOOM=1`
