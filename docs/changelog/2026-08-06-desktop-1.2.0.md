**Date:** 2026-08-06

## User-facing summary

Camxora **1.2.0** hardens Progress disk authority, adds **Download missing MP3s**, fixes export/merge path + quality gates, and cleans release ConnectError / Image source UI.

### Progress / music

- Remap API absolute `run_dir` under this PC’s Suno root (`channel/date_album`).
- **Download missing MP3s (N)** (role-scoped; no re-draft / re-Suno).
- Music **% / X/Y** from landed role MP3s when the folder is scannable.
- Done / Completed / YouTube: hide Continue / Stop / Cancel / export retries.
- Change Run Folder persists batch run key (`persist_batch_run_dir`).
- Active only + Stage filters apply **before** Limit.

### Export / merge

- Recommended bitrate; Quality / Best Quality speed tiers; safer worker caps.
- Manual export merge path uses real `{stem}.mp4` outputs.
- Usable-MP4 gate; lossless merge stream-copy; determinate merge %.

### Image / connectivity

- Category + Prompt only in source UI (User reference hidden until P2).
- Release ConnectError copy no longer mentions `uvicorn` / port 8000.
