## Drift

Live lots claim **102,950 credits**; wallets hold **51,025.25**. Lots overstate the
real balance by **2.0×**. This is the never-decremented-lot bug and the reason migration
174 rebuilds every wallet from `credit_wallets.balance`.

## Snapshot

DB is ~2 GB. Before applying:

```bash
sudo -u postgres pg_dump -Fc camxora_platform \
  -f /opt/camxora/backups/camxora_platform_pre174_$(date +%Y%m%d_%H%M).dump
```

Verify on staging:

```bash
createdb camxora_staging
pg_restore -d camxora_staging /opt/camxora/backups/<file>.dump
```
