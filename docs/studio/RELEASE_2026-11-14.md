## What ships

- **Create → Sounds**: `POST /api/v3/web-music/sounds`, shared queue, `kind='sounds'`,
  musicapi's existing `POST /v1/sounds`.
- **Song → Sample this song**: `sample_task_id`/`sample_variant`, durable audio URL in
  `reference_audio_urls`, forwarded as `audioUrls` to the existing agentic reference path.
- **Song → Use as Inspiration**, song → Studio create-or-load deep links, Learning Center,
  Library upload/record deep links.
- **Rhythm Gate** correction (plugin catalog/audio/codec, legacy `chorus` migration).
- Removed dead controls: Speech, Hooks, custom-model rows, master Reverb ghost, unreachable
  saved-styles popover, duplicate Public pill, `unverified` badge.

## Order

1. **Apply platform migrations** (the full deploy does this automatically; the API startup
   runner also upgrades to head):
   ```bash
   platform_api/.venv/bin/python -m platform_api.migrations.upgrade
   # expect alembic_version = 201
   ```
2. **Web + platform** from `origin/main`:
   ```bash
   python scripts/deploy/deploy_production.py
   ```
   This packages the commit, verifies the manifest, runs migrations, builds
   `website`/`music_web`, and restarts the API.
3. **musicapi** (no new migration this release; the sounds/sample provider paths already
   exist in `musicapi`):
   ```bash
   python scripts/deploy/deploy_musicapi_production.py --yes
   ```
4. **Smoke checks**
   - `https://api.camxora.com/health` and `https://musicapi.camxora.com/health` → 200.
   - Unauthenticated `GET /api/v3/web-music/studio/projects/<id>/plugins/author/<job>` → 401
     (route present).
   - Unauthenticated `POST /api/v3/web-music/sounds` → 401 (not 404).
   - `camxora.com` still serves the marketing site; `music.camxora.com` unchanged.
   - Manual, credit-spending: one Sounds creation and one Sample this song from an owned
     song, then confirm the queued task reaches `success` and plays.
5. **Record** the new `.deployed.json` commit and re-run:
   ```bash
   python scripts/deploy/check_deploy_guards.py production --verify-live
   ```

## Rollback

- Redeploy the previous verified commit: `deploy_production.py --source-ref 985ccf00`
  (the musicapi stack has no schema change in this release).
- Migrations `200`/`201` are additive (`kind` defaults to `music`,
  `reference_audio_urls` defaults to `[]`), so they can stay in place for an app rollback.

## Known non-blocking notes

- The generated “sample” is a full song that references the source audio, not a shorter
  clip; it matches musicapi's audio-reference generation.
- Sounds is charged at the music price until the pricing table gets a dedicated `sounds`
  row (admin-editable; no code change needed).
