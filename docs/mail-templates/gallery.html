CAMXORA — mail templates

Seven standalone emails, sized for a 600px body with table layout and inline styles so Outlook, Gmail and Apple Mail all render them the same way. Each one below is the real file, loaded directly.

Placeholders like {{first_name}}, {{credits}} and {{code}} appear literally here. In production they are replaced per recipient at send time, and the pack numbers in the ladder are rendered from credit_packs so a repricing cannot leave the copy stale.
Files live in docs/mail-templates/. Every one includes a preheader, a 1px open pixel target ({{app_url}} links become signed redirects at send time), and an unsubscribe link except the receipt, which is transactional.
