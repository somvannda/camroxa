# Codebase audit — 2026-10-05

Whole-repository bug/gap hunt and the disposition of every finding. Scope: active product
(`musicapi/` core + `web-user` + `web-admin` + `lrc-service` + `midi-service`), legacy backend
(`platform_api/`), legacy web (`admin_portal/`, `user_portal/`, `website/`, `music_web/`), desktop
(`camxora_python/`), and deploy automation (`scripts/deploy/`). Generated/vendor dirs excluded.

Status legend: **Fixed** (merged), **Deferred** (intentionally not fixed), **Open** (needs a
decision or is non-code).

Roll-up PRs: **#299** (security phases 0–4 + extras), **#303** (desktop), **#304** (remaining items).

## Open / non-code items

1. **Rotate** the two leaked admin credentials and **purge them from git history** (BFG / `git
   filter-repo`). The code no longer contains them; history does.
2. **Manual desktop GUI smoke test**: settings "My prompts", Suno lyrics online check, music page
   Generate.
3. **Geo gate (edge step)**: the app-side trusted-edge gate is in place but **opt-in**. To close it:
   set `PLATFORM_MUSIC_WEB_TRUSTED_EDGE_SECRET` on the API, have nginx send the same value as
   `proxy_set_header X-Origin-Verify "<secret>";` in the music-web server block, and restrict the
   origin firewall to Cloudflare's published ranges (`https://www.cloudflare.com/ips-v4` +
   `ips-v6`). With the secret unset, the gate keeps the legacy behavior (sandbox/dev) — so prod is
   unchanged until you enable it.
4. **Pre-existing** `camxora_python` test failures (15), identical on clean `main`; one is a local
   untracked `.env.sandbox`/`.env.production` artifact.
