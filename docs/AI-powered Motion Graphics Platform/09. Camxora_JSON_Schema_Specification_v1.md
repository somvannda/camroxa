# Camxora JSON Schema Specification
## Version 1.0 (Draft)

# Purpose

This document defines the canonical JSON model for every Camxora project.
JSON is the single source of truth shared by the Studio UI, AI Designer,
Renderer, Templates, Plugins, and Cloud services.

---

# Design Principles

- Human readable
- Versioned
- Extensible
- Backward compatible
- Schema validated
- AI editable

---

# Root Structure

```json
{
  "project": {},
  "settings": {},
  "assets": [],
  "scenes": []
}
```

---

# Project

```json
{
  "id":"project.uuid",
  "name":"My Project",
  "version":"1.0.0",
  "createdAt":"",
  "updatedAt":"",
  "engineVersion":"1.0.0"
}
```

Fields

- id
- name
- author
- description
- version
- createdAt
- updatedAt
- engineVersion

---

# Scene

```json
{
  "id":"scene.main",
  "name":"Main Scene",
  "objects":[]
}
```

Each project supports unlimited scenes.

---

# Scene Object

```json
{
  "id":"obj001",
  "type":"Spectrum",
  "name":"Main Spectrum",
  "enabled":true,
  "components":[]
}
```

Supported types

- Background
- Spectrum
- Logo
- Text
- Particles
- Lighting
- Camera
- Overlay
- PostProcessing

---

# Component

```json
{
  "type":"Material",
  "properties":{}
}
```

Supported components

- Transform
- Material
- Animation
- AudioReaction
- Metadata
- Renderer

# Validation Rules

Required

- id
- type
- version

Validation

- Unique IDs
- Valid asset references
- Compatible engine version
- Supported plugins
- Schema compliance

---

# Versioning

Semantic Versioning

Major.Minor.Patch

Migration Rules

- Automatic migration when possible
- Preserve unknown fields
- Warn on deprecated fields

---

# AI Rules

The AI may:

- Read JSON
- Create JSON
- Modify JSON
- Validate JSON

The AI must never:

- Produce invalid schema
- Remove required fields
- Break references
