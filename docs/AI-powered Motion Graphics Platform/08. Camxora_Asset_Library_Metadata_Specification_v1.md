# Camxora Asset Library & Metadata Specification
## Version 1.0 (Draft)

# Purpose

The Asset Library is the centralized repository for every reusable asset used by
Camxora. It enables users, AI, and plugins to discover, reuse, organize, and
manage assets consistently.

Every asset is described by structured metadata and stored independently from
scenes.

JSON is the single source of truth.

# AI Responsibilities

AI may

- Search assets
- Recommend assets
- Rank assets
- Explain recommendations
- Create templates from assets

AI must never

- Duplicate existing assets unnecessarily
- Ignore compatibility rules
- Generate invalid metadata

---

# Design Principles

1. Every asset is reusable.
2. Metadata is mandatory.
3. Assets are independent from scenes.
4. AI depends on metadata, not filenames.
5. Every asset has previews.
6. Assets remain editable.
7. Plugin assets behave exactly like built-in assets.

---

# Long-Term Vision

The Asset Library becomes the knowledge foundation of Camxora. As the library
grows, AI gains better understanding of design intent, users discover assets
faster, and the marketplace can distribute reusable creative building blocks
across the entire ecosystem.
