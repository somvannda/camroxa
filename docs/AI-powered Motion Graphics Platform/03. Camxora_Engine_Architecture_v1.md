# Camxora Engine Architecture

## Purpose
A modular, AI-native motion graphics engine built around reusable components, a scene graph, and JSON as the single source of truth.

## Principles
- Component-based
- JSON-driven
- AI-native
- Plugin-ready
- GPU accelerated
- Extensible

## High-Level Architecture

```text
AI Designer
    │
    ▼
Scene JSON Generator
    │
    ▼
Scene Graph Engine
 ├─ Background
 ├─ Spectrum
 ├─ Logo
 ├─ Particles
 ├─ Lighting
 ├─ Camera
 ├─ Audio
 └─ Post Processing
    │
    ▼
Render Pipeline
    │
    ▼
Preview / Export
```

## Core Modules

### Scene Graph
Responsibilities:
- Object hierarchy
- Parent/child relationships
- Layer ordering
- Visibility
- Serialization

### Component System
Each SceneObject contains:
- Transform
- Material
- Animation
- AudioReaction
- Renderer
- Metadata

### Asset Library
Libraries:
- Spectrum
- Background
- Materials
- Particles
- Lighting
- Camera
- Animation
- Color Palettes
- Audio Presets

Each asset stores:
- ID
- Name
- Preview
- Tags
- JSON
- Compatibility
- Version

### Animation Engine
Supports:
- Keyframes
- Curves
- Looping
- Noise
- Physics
- Audio-driven animation

### Audio Engine
Provides:
- FFT
- Beat Detection
- BPM
- Bass
- Mid
- Treble
- Kick
- Snare
- Vocal

### Render Pipeline
Geometry
→ Materials
→ Lighting
→ Particles
→ Post Processing
→ Encoder

Outputs:
- Preview
- MP4
- MOV
- Image Sequence
- Thumbnail

### Post Processing
- Bloom
- HDR
- Tone Mapping
- Color LUT
- Exposure
- Contrast
- Gamma
- Motion Blur
- Sharpen
- Vignette
- Chromatic Aberration
- Lens Distortion

### AI Layer
AI responsibilities:
- Understand prompts
- Generate Scene JSON
- Recommend assets
- Modify scenes
- Explain changes

AI does **not** render frames.

### JSON Architecture

```text
Project
└── Scene
    ├── Objects
    ├── Components
    ├── Materials
    ├── Animations
    ├── Audio Mapping
    └── Metadata
```

JSON is the single source of truth.

### Plugin Architecture
Plugin types:
- Spectrum
- Particle
- Material
- Renderer
- Camera
- Import
- Export
- AI

Each plugin provides:
- Metadata
- Settings UI
- JSON Schema
- Compatibility Rules

## Performance Targets
- 60 FPS editing
- GPU acceleration
- Multi-thread rendering
- Asset caching
- Lazy loading

## Design Rules
1. Scene Graph is the core.
2. Everything is a component.
3. JSON drives UI, AI, rendering and templates.
4. AI edits data, not pixels.
5. Every module is reusable.
6. Plugin-first architecture.

## Long-Term Vision
Camxora evolves into a complete AI-native motion graphics platform with a reusable rendering engine, intelligent scene generation, and an extensible plugin ecosystem.
